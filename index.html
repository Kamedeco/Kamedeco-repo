About the Quiz

Game Overview

This world map quiz contains 197 countries divided into various regions. This map consists of UN regognized countries with the addition of Kosovo, Taiwan, Palestine, and Israel. Users can click on a region to start a game. Games are saved so players can exit the page or attempt a different region/mode without losing progress. These saves are removed when players click the quit game button at the top right or when the player finishes their game. There are 3 modes: countries, flags, and capitals. All modes have players click the proper country when given a prompt. The average of a player's last two scores are saved. Players can view scores in the side panel and switch between modes with the dropdown menu. Scores are saved locally to your browser. Players can also view a refreshable random fact above the map.

Behind the Scenes

This website uses D3.js for data visualization and boostrap 5.3 for styling. QGIS was used to make custom outlines for small countries (e.g. Kiribati, Somoa, The Bahamas, etc). Icons were provided by Font Awesome.
